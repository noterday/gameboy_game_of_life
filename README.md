# Conway's Game Of Life homebrew Gameboy project
Done slowly throughout the first half of 2026, to learn a lot of assembly programming basics.
With insight, there are many things I would likely change, but it is stable and runs at a reasonable speed.
Tested in Emulicious and Mister.

## Controls
- A: Draw
- B: Tick forward one generation
- Start: Switch between Drawing / Play state
- Select: Reset
